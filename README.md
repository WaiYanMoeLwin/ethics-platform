An interactive web-based learning platform that teaches ethical data collection
in personalized software, together with the study apparatus to measure whether
it works.

Built for **953420 — Ethics and Professionalism for Software Engineers**

## What it contains

- **Five modules** — the personalization–privacy trade-off, informed consent,
  data minimization, purpose limitation, and sensitive data. Each is a 4–5 minute
  read with one or two real case studies and a short formative quiz.
- **Scenario Lab** — seven decisions framed from the developer's chair (a ticket,
  a PM request, a code review). The learner gives a verdict and gets reasoned
  feedback, including a clearly ethical case and a genuinely contested one.
- **Study flow** — a self-invented participant code plus links out to the
  pre-test, post-test, and feedback survey (Google Forms).
